## 🌟 Key Website Features

- **Dual-Video Hero Crossfade:** Seamless background video looping transition with smooth opacity crossfades and video fallback poster support.
- **Accessibility & Motion Preferences:** Automatically detects `prefers-reduced-motion` to disable resource-heavy video transitions, parallax, and intense animations.
- **Static Categorized Tech Stack:** Clear, accessible tech stack grid organized across 8 distinct technology categories with responsive pill badges and hover accents.
- **Accessible Project Modals:** Dedicated modal windows for case studies (`Hotel Website`, `Architecture Company Website`, `Custom Mobile Application`) with backdrop-click, keyboard trap, and `Escape` key listeners.
- **AJAX Netlify Forms:** Fully integrated contact form with client-side field validation, anti-spam honeypot field (`bot-field`), asynchronous submission (`fetch`), loading states, and inline error/success messaging.
- **Modern Dark UI:** Tailored dark aesthetic with violet/purple accents (`#8B5CF6`, `#A78BFA`), glassmorphic panels, and refined typography.
- **Responsive Navigation:** Fixed navigation header with scroll-aware styling, mobile hamburger overlay menu, and smooth scrolling to page anchors with navbar height offset compensation.
- **Scroll Animations:** Lightweight `IntersectionObserver` scroll reveals for staggered component animations without external library overhead.
- **Zero Build Dependencies:** Pure native web technologies without npm install, bundle, or compiler requirements.

## 🚀 Getting Started Locally

Because the project is built with standard web technologies, it requires **no compiler, bundler, or build step**.

### Prerequisites
- Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
- A local HTTP server (recommended so that video assets and fetch requests execute without local file-origin restrictions).

### 1. Clone the Repository
```bash
git clone https://github.com/varshithreddy1109/varxosolution.git
cd varxosolution
```

### 2. Run a Local Development Server

Run any of the following lightweight servers from the project root:

**Using Python (built into macOS, Linux, and Windows):**
```bash
# Python 3
python -m http.server 8000
```
Then visit: `http://localhost:8000`

**Using Node.js (`npx serve` or `http-server`):**
```bash
npx serve .
```

**Using VS Code Live Server extension:**
1. Open the project folder in **Visual Studio Code**.
2. Right-click `index.html` in the file explorer.
3. Select **"Open with Live Server"**.

## 🌐 Deployment Instructions (Netlify)

This project is tailored for static hosting on **Netlify**.

### Option A: Automatic Git Integration (Recommended)
1. Push your latest code to your GitHub repository:
   ```bash
   git push origin main
   ```
2. Log in to [Netlify](https://app.netlify.com/).
3. Click **"Add new site"** > **"Import an existing project"**.
4. Select **GitHub** and authorize access to `varshithreddy1109/varxosolution`.
5. Configure deployment settings:
   - **Branch to deploy:** `main`
   - **Base directory:** *(leave empty)*
   - **Build command:** *(leave empty — static site)*
   - **Publish directory:** `.` *(or leave empty / root)*
6. Click **"Deploy site"**. Netlify will build and provide a live URL (`https://<your-site-name>.netlify.app`).

### Option B: Netlify Drag & Drop
1. Log in to your [Netlify Dashboard](https://app.netlify.com/).
2. Navigate to the **"Sites"** tab.
3. Drag and drop the `company website` project folder directly into the upload area.
4. Your site will be published immediately.

## 📬 Netlify Forms Configuration

The contact form is pre-configured to work seamlessly with **Netlify Forms**:

```html
<form id="contactForm" name="contact" method="POST" action="/" data-netlify="true" data-netlify-honeypot="bot-field" novalidate>
  <input type="hidden" name="form-name" value="contact" />
  <p style="display:none;" aria-hidden="true">
    <label>Don’t fill this out if you're human: <input name="bot-field" tabindex="-1" autocomplete="off" /></label>
  </p>
  ...
</form>
```

### How Submissions Work:
1. **Form Discovery:** Netlify's build bots parse HTML files upon deployment and detect the `data-netlify="true"` attribute and form name `contact`.
2. **Spam Mitigation:** The hidden `bot-field` input traps automated spam bots while remaining invisible to regular users.
3. **AJAX Submission:** `js/main.js` catches form submission, runs validation, and performs a `POST` request with `Content-Type: application/x-www-form-urlencoded`.
4. **Viewing Submissions:**
   - Go to your **Netlify Dashboard**.
   - Select your site and navigate to **Site configuration > Forms** (or **Forms** tab).
   - Under active forms, select `contact` to view incoming inquiries.
5. **Email Notifications:**
   - Under **Site configuration > Forms > Form notifications**, click **Add notification**.
   - Select **Email notification** and enter your inbox address to receive instant alerts on new leads.

> **Note on Local Testing:** Netlify Forms handling is processed by Netlify's backend servers. When submitting the form on `localhost`, the fetch call will fail with a test error notice; submissions will register as soon as the site is deployed to Netlify.

## 🎨 Customization Guide

### 1. Updating Brand Details & Contact Info
- **Email, Phone & Social Links:** Open `index.html` and search for the `<!-- REPLACE: ... -->` comments in the `#contact` and `#footer` sections.
- **Hero Video & Poster:** To customize the hero video background, replace the video and poster URLs in lines 66–72 of `index.html`.

### 2. Updating Showcase Projects
- **Modal Descriptions:** Edit the modal content in `index.html` under the `<!-- PROJECT DETAIL MODALS -->` section.
- **Cards & Visuals:** Place your actual project screenshots in the `assets/` directory and update the mockup containers in `index.html`.

### 3. Customizing the Technologies Section
- The technologies section is structured cleanly in `index.html` under `<div class="tech-categories">`. You can add, edit, or reorganize categories and badges directly in the HTML.

### 4. Adjusting Colors and Styles
Global design tokens are organized at the top of `css/style.css`:
```css
:root {
  --bg: #000000;
  --text-primary: #FFFFFF;
  --text-muted: #888888;
  --accent-purple: #8B5CF6;
  --accent-violet: #A78BFA;
  --panel-dark: #181818;
  /* ... */
}
```
